# 诺基亚助手

面向**功能机（Feature Phone）浏览器**的动态网站，使用 Flask 编写。

设计原则：

- 一切动态内容**服务端渲染**，输出**纯 HTML**：无 CSS、无 JavaScript、无复杂布局、无表格排版，页面小、加载快。
  主导航使用 `accesskey` 数字快捷键（部分功能机支持按数字键直达）。
- 全站响应头 `Cache-Control: no-store`，避免功能机代理缓存导致内容过期；AI 回复靠页面上的「刷新」链接手动获取。
- 账号体系全站共用一次登录（签名 Cookie 会话），三个服务状态同步。
- 数据保存在 SQLite（`data/nokia.db`），小说正文以 UTF-8 文本文件存放在 `data/novels/`。

## 功能

1. **网页辅助浏览** `/browse`
   - 服务器代为抓取网页（仅公网 http/https，含基础 SSRF 防护）。
   - 去除 CSS / JS / 图片 / 注释等非交互节点；**保留搜索框、下拉框、按钮等交互元素**，表单统一转为经代理的 GET 提交（字段并入目标地址）。
   - 自动识别编码，超大页面按约 5000 字符/页分页，链接全部重写为站内代理链接。
   - 附必应搜索入口（同样经代理输出纯文字）。
2. **AI 对话** `/ai/`（需登录）
   - **模型分三层**：
     - *内置免费模型*：`data/api_keys.json` 的 `free_groups`（Radeon / NVIDIA NIM），**所有人可用（含未登录游客）**；
     - *本地聚合 magpie*（`127.0.0.1:1234`）：同文件 `magpie` 段，仅 `config.json` 中特权用户可用；
     - *个人接口*：登录用户在 AI 设置里导入，存于数据库随账号保存。
   - 每条消息可从下拉框选择模型；回复下方显示所用模型。
   - 兼容 OpenAI `/chat/completions` 接口；个人接口地址、密钥、模型、系统提示、温度随账号保存。
   - **非流式**：发送后服务端后台线程调用接口，页面提示「正在生成」，**手动刷新**即可看到回复；失败可重试。
   - 支持多会话管理（创建、续聊、删除），上下文自动携带最近 12 条消息。
   - 设置页含「测试连接」。
3. **云小说** `/novel`
   - 登录后可上传 TXT（支持 UTF-8 / GBK / Big5 / UTF-16 自动识别）或直接粘贴文本，最多 15MB。
   - 每用户书库总容量 **2MB**；`config.json` 中 `privileged_users` 列表内的用户名
     为特权用户，容量无上限（每次请求重新读取配置，改后无需重启）。
   - 登录后显示书架（阅读 / 目录 / 分享链接 / 删除）。
   - 未登录用户凭分享链接 `/n/<随机码>` 可直接阅读，无需账号。
   - 自动识别「第 X 章」类章节标题生成目录；正文按每页 500 字硬切分页阅读，支持上一页/下一页/上一章/下一章。

## 运行

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./run.sh            # 默认 0.0.0.0:8000，PORT=8080 ./run.sh 可改端口
```

手机浏览器访问 `http://<电脑IP>:8000/` 即可。

## 测试

```sh
# 先启动本地模拟 OpenAI 接口（AI 对话测试用）
.venv/bin/python tests/mock_openai.py &
# 再跑端到端测试（会自动注册临时账号并上传测试小说）
.venv/bin/python tests/test_flow.py
```

测试覆盖：注册/登录/登出、代理清洗与分页（注释/脚本/样式/图片去除、交互表单保留与代理提交、链接重写、SSRF 拦截、超长分页完整性）、
AI 设置保存/测试连接/异步生成与手动刷新/错误重试、小说上传（UTF-8/GBK）/章节识别/免登录阅读/删除，以及全部页面无 CSS/JS 且体积小于 8KB。

## 说明

- API 密钥以明文存于本地 SQLite，请勿在不可信环境部署；该服务仅设计用于个人/局域网使用。
- 内置模型密钥在 `data/api_keys.json`（600 权限），特权名单在 `config.json`，两者均已 gitignore；
  仓库内提供 `api_keys.example.json` 与 `config.example.json` 作为格式参考。
- 网页代理把表单统一转为 GET 经代理提交，适合搜索等场景；需要 POST 且带会话的登录类页面不可用。
- `secret.key` 为会话签名密钥，首次启动自动生成，删除后所有登录态失效。
- 网页代理拦截明确的内网地址段以防 SSRF；放行 `198.18.0.0/15`（本地代理 fake-ip 模式的虚拟网段）。
